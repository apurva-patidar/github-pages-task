# Static Website Using GitHub Pages

## Project Overview
This project demonstrates how to create and deploy a static website using GitHub Pages.

## Objective
To host a simple HTML website publicly on the internet for free.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Features
- Simple and responsive webpage
- Custom CSS styling
- Public website hosting

## Live Website
https://apurva-patidar.github.io/github-pages-task/

## Deployment Steps
1. Created an `index.html` file.
2. Initialized Git in the project directory.
3. Pushed the project to GitHub.
4. Enabled GitHub Pages from the repository Settings.
5. Selected the `main` branch and root folder.
6. Verified the live website.

## Learning Outcome
Learned the basics of static website hosting and deployment using GitHub Pages.
